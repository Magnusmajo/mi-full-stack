## Método de trabajo

Enseñanza → comprensión → código propio → revisión → documentación.

Las carpetas no representan temas completados. Cada explicación, ejemplo y reflexión se incorporará después de practicar y revisar. Cada módulo tiene carpetas `exercises/` y `projects/`; los temas tendrán su propio README cuando haya aprendizaje que documentar. Los archivos `.gitkeep` conservan las carpetas vacías en Git y pueden retirarse cuando se añada contenido.
