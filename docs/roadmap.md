## Prácticas continuas

- Usar Git desde el primer día, durante los 280 días.
- Incorporar ramas, merge, rebase, pull requests, tags, releases e issues gradualmente.
- Aplicar accesibilidad, pruebas y seguridad durante las prácticas, además de sus módulos específicos.
- Seguir el ciclo: enseñanza → comprensión → código propio → revisión → documentación.
- Reservar tiempo para repasar y corregir. El calendario no obliga a marcar temas incompletos.

## Proyecto integrador

Definir problema, alcance y criterios de aceptación antes de implementar. Elegir tecnologías según los requisitos y documentar las decisiones. Entregar código ejecutable, instrucciones, pruebas, despliegue y demo.
